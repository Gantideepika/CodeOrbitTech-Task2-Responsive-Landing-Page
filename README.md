
# Dream2Work - Responsive Landing Page

## CodeOrbitTech Internship - Task 2

Dream2Work is a responsive multi-page landing website designed around the idea of connecting people with opportunities based on their skills, interests, and passions.

## Pages

- Home
- Features
- How It Works
- Contact

## Features

- Responsive design
- Multi-page navigation
- Professional landing page layout
- Skill-based opportunities
- Passion-based opportunities
- Smart recommendations concept
- Career and opportunity exploration
- Mobile, tablet, and desktop support
- Hover effects
- Sticky navigation

## Technologies Used

- HTML5
- CSS3
